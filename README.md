# Cryptlex On-premise

Self-host the complete Cryptlex platform (Web API, Web Portals, and Release Server) on your own infrastructure. It has all the features of SaaS Cryptlex, and regular releases keep you up to date.

## Deployment options

| Option                                         | Best for                                       | Runs on                                   |
| ---------------------------------------------- | ---------------------------------------------- | ----------------------------------------- |
| [Docker Compose](docker-compose/README.md)     | Single-server deployments                      | One Linux server with Docker              |
| [Kubernetes](kubernetes/README.md)             | High-availability deployments                  | A Kubernetes cluster, installed with Helm |

Both options need a Cryptlex license key and access to the private Cryptlex images on Docker Hub. If you are installing for the first time, [contact us](https://cryptlex.com/contact) to schedule a guided installation.
